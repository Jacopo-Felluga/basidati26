# Sistema Gestione Centro Fitness Pushup.Dev

Questo progetto è un'applicazione web sviluppata collegata a un database per la gestione completa di una palestra (iscritti, abbonamenti, corsi e istruttori). Il progetto è stato realizzato in PHP, dato il fatto che lo ho studiato come linguaggio alle superiori. Ho inoltre deciso di aggiungere <strong>Boostrap per i CSS</strong> di modo da rendere il tutto un po' più moderno.
