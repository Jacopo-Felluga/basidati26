# Sistema Gestione Centro Fitness

Questo progetto è un'applicazione web in PHP collegata a un database per la gestione completa di una palestra (iscritti, abbonamenti, corsi e istruttori). Il progetto è stato realizzato in PHP, dato il fatto che lo ho studiato come linguaggio alle superiori.
