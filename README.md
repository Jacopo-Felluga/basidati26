# Sistema Gestione Centro Fitness

Questo progetto è un'applicazione web in PHP collegata a un database per la gestione completa di una palestra (iscritti, abbonamenti, corsi e istruttori). L'ho realizzato come progetto d'esame per l'insegnamento di Basi di Dati, implementando i vincoli e i trigger direttamente nel database per evitare problemi come la sovrapposizione degli orari o il superamento della capienza delle sale.
